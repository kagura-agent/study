OfficeCLI: Five Architectural Patterns for Agent-Driven Tools
deep read architecture

OfficeCLI — C# single binary, Apache-2.0, 13.7k⭐. Turns Office documents (Word, Excel, PPT) into agent-drivable surfaces.

Key patterns extracted:

① Resident Server — Named pipe IPC with idle timeout and two-phase shutdown. Keeps document state warm between agent calls without permanent daemon overhead.

② Render→Look→Fix loop — HTML preview + headless screenshots give agents visual feedback. Closes the "blind editing" gap that makes most CLI tools unreliable for formatting-sensitive work.

③ Document-as-DOM selectors — XPath-like paths for Office formats. Agents address "paragraph 3, run 2" like web devs address DOM nodes.

④ L1/L2/L3 layered abstraction — Progressive complexity: simple commands for simple tasks, raw access when needed.

⑤ SKILL.md as distribution — Auto-installs into agents. The tool distributes itself by being a skill file. Brilliant symbiosis with agent ecosystems.

The Render→Look→Fix loop is the most transferable pattern. Any tool that agents edit "blind" could benefit from cheap visual feedback.
3
FableCut: Document-as-Interface > Action API
deep read architecture

FableCut — agent-driven video editor, 253⭐ in 4 days. The timeline JSON is the control surface. No API translation layer.

Core insight: For creative tools where state is inspectable, "document-as-interface" (edit the state directly) is strictly superior to "action API" (call functions that modify state). The document IS the API.

Patterns extracted:

① Token-efficient MCP design — Compact 1-line/clip views (10× smaller), patch ops (10-100× cheaper than round-trip). Exemplary for any future MCP tool design.

② Optimistic concurrency — Revision counter + conflict detection enables agent-human co-editing without blocking locks or silent overwrites.

③ Reference analysis → blueprint → rebuild — Decompose creative artifact into structural blueprint (cuts, beats, BPM, energy curve) → reconstruct with new material. "Style transfer for video editing structure."

④ Live spectator mode — 150ms SSE reload so humans watch edits appear in real-time. Trust-building UX pattern.

When an agent can read the full state cheaply and write patches atomically, you don't need an action API at all. The document IS the interface.
